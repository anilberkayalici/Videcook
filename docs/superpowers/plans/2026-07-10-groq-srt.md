# Groq SRT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** Convert a user-selected English audio file into an English `.srt` file using the user's own Groq API key.

**Architecture:** The subtitle page owns file selection and progress. A background worker normalizes audio with the bundled FFmpeg, creates short overlapping chunks, sends them sequentially to Groq, and turns timestamped segments into one SRT file. The API key is stored with Windows DPAPI, never in `videcook_prefs.json`.

**Tech Stack:** Python 3.11+, PySide6, bundled FFmpeg/FFprobe, Groq REST API, Windows DPAPI, pytest.

## Global Constraints

- The feature targets English speech transcription, not translation.
- A user must provide their own Groq API key; no key is embedded in the application.
- Groq requests must use `whisper-large-v3` and `verbose_json` segment timestamps.
- Chunks are processed sequentially with one-second overlap and retry on rate limiting.
- Temporary normalized audio and chunks are removed after success, cancellation, or failure.
